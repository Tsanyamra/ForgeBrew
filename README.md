## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ForgeBrew.git`
2. `cd ForgeBrew`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ForgeBrew, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
